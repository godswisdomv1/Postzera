# Postzera

One post, every platform. Write one master post and Postzera turns it into a ready-to-send image or video for each social platform, with a reminder and a one-tap share for each.

Identifier: `com.zdmgold.postzera`

## Analysis commands

Run from `app/`:

```bash
flutter pub get
flutter gen-l10n
flutter analyze --no-fatal-infos
flutter test
```

The full architecture is described in the Postzera Master Architecture Blueprint. This README is replaced at the end of the build.
